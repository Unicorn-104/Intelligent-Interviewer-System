## 2. `<script setup>` 结构模板

所有 CRUD 页面统一以下结构顺序：

```vue
<script setup name="ModuleName">
// ==================== 1. Import ====================
import { listXxx } from "@/api/xxx"

// ==================== 2. Setup ====================
const { proxy } = getCurrentInstance()

// ==================== 3. State (all individual refs) ====================
const tableList = ref([])
const loading = ref(false)
const showSearch = ref(true)
const total = ref(0)
const ids = ref([])
const single = ref(true)
const multiple = ref(true)
const dialogOpen = ref(false)
const dialogTitle = ref("")
const formData = ref({})
const formRules = { ... }

const queryParams = reactive({ pageNum: 1, pageSize: 10 })

// ==================== 4. Computed ====================
const isMultiple = computed(() => ids.value.length > 0)

// ==================== 5. Methods ====================
function getList() { /* ... */ }
function handleQuery() { /* ... */ }
function resetQuery() { /* ... */ }
function handleSelectionChange(sel) { /* ... */ }
function handleAdd() { /* ... */ }
function handleUpdate(row) { /* ... */ }
function submitForm() { /* ... */ }
function handleDelete(row) { /* ... */ }

// ==================== 6. Lifecycle ====================
getList()
</script>
```

**禁止使用 `reactive + toRefs` 组合模式处理单个字段**。仅 `queryParams` 和 `form` 使用 `reactive()`。其他状态全部使用独立 `ref()`。

## 3. API 调用规范

### 3.1 必须包含错误处理和 finally

```js
// ✅ 正确
function getList() {
  loading.value = true
  listXxx(queryParams).then(res => {
    tableList.value = res.rows
    total.value = res.total
  }).catch(err => {
    console.error(err)
    proxy.$modal.msgError('查询失败，请重试')
  }).finally(() => { loading.value = false })
}

// ❌ 错误 - 缺少 catch 和 finally
listXxx().then(res => { data.value = res.rows })
```

### 3.2 confirm 对话框必须有 .catch()

```js
proxy.$modal.confirm('确认删除？').then(() => {
  delXxx(id).then(() => {
    proxy.$modal.msgSuccess('删除成功')
    getList()
  }).catch(err => { console.error(err); proxy.$modal.msgError('删除失败') })
}).catch(() => {}) // 用户取消
```

## 4. 函数声明规范

### 4.1 禁止单行多函数 / 过长的单行函数

```js
// ❌ 错误
function statusTag(v) { const m = { pending: 'warning', evaluated: 'primary' }; return m[v] || 'info' }
function scoreColor(v) { return v >= 80 ? '#22C55E' : v >= 60 ? '#F59E0B' : '#EF4444' }

// ✅ 正确
function statusTag(v) {
  const map = { pending: 'warning', evaluated: 'primary', passed: 'success', rejected: 'danger' }
  return map[v] || 'info'
}

function scoreColor(v) {
  if (v >= 80) return '#22C55E'
  if (v >= 60) return '#F59E0B'
  return '#EF4444'
}
```

### 4.2 条件映射用 Map 对象

```js
// ✅ 推荐
const STATUS_MAP = {
  pending: 'warning', evaluated: 'primary', passed: 'success', rejected: 'danger'
}
function statusTag(v) { return STATUS_MAP[v] || 'info' }
```

## 5. 表格规范

### 5.1 必须包含 selection 列

```html
<el-table :data="tableList" @selection-change="handleSelectionChange" stripe>
  <el-table-column type="selection" width="55" align="center" />
  <!-- 数据列 -->
</el-table>
```

```js
function handleSelectionChange(sel) {
  ids.value = sel.map(r => r.xId)
  single.value = sel.length !== 1
  multiple.value = !sel.length
}
```

### 5.2 列宽标准

| 列类型 | 宽度设置 |
|--------|----------|
| ID / 序号 | `width="80"`~`100` |
| 名称 / 手机号 | `width="120"`~`160` |
| 长文本（溢出省略） | `min-width="200"` + `show-overflow-tooltip` |
| 时间 | `width="160"` 或 `"180"` |
| 操作 | `width="150"`~`200"` |
| 评分/状态标签 | `width="80"`~`120` |

## 6. 表单与对话框规范

### 6.1 必须配置 `:rules`

```html
<el-form ref="formRef" :model="formData" :rules="formRules" label-width="100px">
  <el-form-item label="名称" prop="name">
    <el-input v-model="formData.name" placeholder="请输入名称" />
  </el-form-item>
</el-form>
```

### 6.2 submit 必须校验

```js
function submitForm() {
  proxy.$refs[formRef].validate(valid => {
    if (!valid) return
    // 提交逻辑
  })
}
```

## 10. Template 表达式规范

模板中只放简单绑定，复杂逻辑抽到方法：

```html
<!-- ✅ 正确 -->
<span>{{ scoreColor(scope.row.score) }}</span>
<el-tag :type="statusTag(scope.row.status)">{{ statusLabel(scope.row.status) }}</el-tag>

<!-- ❌ 错误 - 模板中嵌套三元运算符 -->
<span style="color: {{ scope.row.score >= 80 ? '#22C55E' : '#EF4444' }}">{{ scope.row.score }}</span>
```

## 12. Code Review Checklist

新建/修改页面时逐项检查：

- [ ] 每个 API 调用都有 `.catch()` 错误处理
- [ ] 列表请求有 `.finally()` 重置 loading
- [ ] 使用 `getCurrentInstance()` 获取 `proxy`
- [ ] 状态使用独立 `ref()`，避免 `reactive + toRefs`
- [ ] 函数分行书写，禁止一行多函数
- [ ] 表格有 `@selection-change` 处理器和 selection 列
- [ ] 表头列宽合理设置
- [ ] 表单有 `:rules` 验证
- [ ] 无空实现函数（未完成的 TODO）
- [ ] 组件 name 符合命名规范
- [ ] 模板中无复杂表达式/嵌套三元运算符
- [ ] 魔法值已提取为常量
