## 一、项目简介

本项目是一套**企业级智能招聘面试官 Agent 系统**，服务于 C 端求职者、B 端 HR、管理员三类用户，覆盖招聘核心、面试评估、在线笔试与双机位、面试流程编排、Agent 管理、Offer 管理、权限角色等业务域。

系统基于 **若依（RuoYi）** 快速开发框架搭建，采用前后端分离架构：

- **后端**：Spring Boot + Spring Security + Redis + JWT，基于 MyBatis 持久层，内置代码生成器、定时任务、服务监控等能力。
- **前端**：Vue3 + Element Plus + Vite + Pinia，含后台管理端与「企业端」招聘业务模块。
- **数据库**：MySQL，共 **81 张表**，划分为 12 大业务模块（详见《数据库设计（精简版v4）.md》）。

## 四、数据库准备

1. 新建数据库：

```sql
CREATE DATABASE recruit_agent DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```


2. 修改数据库连接配置：

编辑 `RuoYiProject/ruoyi-admin/src/main/resources/application-druid.yml`：

```yaml
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://localhost:3306/recruit_agent?...
        username: root
        password: 你的数据库密码
```

> Redis 连接配置同样在该文件（默认 `localhost:6379`，无密码）。

## 五、后端启动

### 方式一：IDE 启动（推荐开发）

1. 用 IDEA 打开 `RuoYiProject`，等待 Maven 依赖下载完成。
2. 运行入口类：

```
RuoYiProject/ruoyi-admin/src/main/java/com/ruoyi/RuoYiApplication.java
```

### 方式二：命令行启动

```bash
cd RuoYiProject
mvn clean package -Dmaven.test.skip=true     # 打包
java -jar ruoyi-admin/target/ruoyi-admin.jar  # 运行
```

也可在 Windows 下双击 `RuoYiProject/bin/run.bat` 或使用 `ry.bat` 进行启停管理。

> 后端默认端口 **8080**，启动成功后可访问：`http://localhost:8080`。

## 六、前端启动

```bash
cd RuoYiVue3/RuoYi-Vue3

# 安装依赖（三选一）
npm install 或者 npm install --registry=https://registry.npmmirror.com
# yarn install
# pnpm install

# 启动开发服务
npm run dev
```

> 前端默认端口 **80**（`http://localhost`）。开发代理已在 `vite.config.js` 中配置：`/dev-api` → `http://localhost:8080`，无需额外配置跨域。

### 生产构建

```bash
npm run build:prod        # 生成 dist/ 目录
npm run build:stage       # 预发环境构建
```

## 八、内置功能

### 8.1 系统基础功能（RuoYi 自带）

1. 用户管理 / 部门管理 / 岗位管理
2. 菜单管理 / 角色管理（含数据权限）

## 十、常见问题

1. **前端启动后页面打不开接口（404/跨域）**
   确认后端已启动（8080），且 `vite.config.js` 中 `/dev-api` 代理 target 指向 `http://localhost:8080`。

2. **Redis 连接失败**
   确认本机 Redis 已启动（`redis-server`），端口 6379；如有密码请在 `application-druid.yml` 中配置。

3. **数据库字段缺失 / 表不存在**
   检查是否按顺序执行了 `migration_t_to_sys_20260922.sql` 与 `reconcile_schema_vue3_20260922.sql` 两个脚本。

4. **端口被占用**
   后端端口在 `application.yml` 的 `server.port` 修改；前端端口在 `vite.config.js` 的 `server.port` 修改。

5. **登录后无菜单**
   执行 `reconcile_schema_vue3_20260922.sql` 补齐 `sys_menu` 路由字段，并确认角色已分配菜单权限。
