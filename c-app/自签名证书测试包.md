# 自签名证书测试包

公开根证书放在 `assets/certificates/baota_root.pem`。原始 PFX/P12 可能包含私钥，保持 Git 忽略，不放入 Flutter assets。提取密码不写入代码、脚本或安装包。

使用编译参数明确启用私有 CA 信任，并传入后端基地址（末尾不带斜杠）：

```powershell
flutter build apk --release --dart-define=API_BASE_URL=https://你的后端地址/prod-api --dart-define=TRUST_BAOTA_CERTIFICATE=true
```

默认不启用。启用后，API、文件上传和 Flutter 网络图片仅在配置后端的 HTTPS 主机及端口使用该根证书；其他地址使用系统信任库。仍校验证书链、有效期及服务器身份。不使用接受所有证书的回调，也不修改系统信任库。私有 CA 请求不自动跟随重定向，以免将该信任带到其他地址。

APK 位于 `build/app/outputs/flutter-apk/app-release.apk`。当前仓库 Release 使用调试签名，供安装测试。更换根 CA 时需重新导出公开证书并打包；同一 CA 签发的新服务器证书仍须包含正确的 IP/域名及有效证书链。

验证：修改文件格式检查、`flutter analyze`、`flutter test`、带上述参数的 Release 构建；在目标设备验证验证码加载、登录、头像、文件上传。自动测试不代替完整业务验收。
