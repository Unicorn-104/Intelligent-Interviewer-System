# 投递简历选择

首页、搜索、AI 推荐、企业主页及职位收藏中的投递入口统一显示简历选择框。
默认选中默认简历；AI 推荐页优先选中生成该批推荐使用的简历。用户可以改选，
确认后提交所选简历 ID，不改变默认简历设置。取消不提交；简历为空时提示先创建或导入；加载失败可重试。

接口仍为 `POST /app/jobs/{positionId}/apply`，新增可选正文：

```json
{"resumeId": 52}
```

服务端校验简历属于当前登录用户且处于有效状态，将 ID 保存到投递记录的 `app_resume_id`。
无效或越权的显式 ID 必须拒绝，不回退到默认简历。
兼容未传正文的旧客户端，仍使用原有默认简历逻辑。无需数据库表结构迁移。

验证覆盖非默认简历入参、默认简历兼容、简历归属与有效状态、重复投递、
选择后确认、取消、空列表和加载失败重试。
