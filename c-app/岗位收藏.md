# 岗位收藏

职位详情右上角书签读取当前用户的真实收藏状态。点击收藏后以服务端返回的 `favorited` 更新实心书签；再次点击取消。状态加载和保存期间禁用按钮，失败保留原状态并提供提示或重试。

个人中心「我的收藏」包含「职位」「企业」两个页签。职位支持分页、下拉刷新、打开详情和直接取消收藏；从详情返回时刷新列表。取消后从第一页重新取数，避免偏移分页漏项。已下架岗位仍展示并可取消收藏，投递按钮禁用。企业页签复用既有企业收藏页面。

## 接口与存储

所有接口使用 Bearer Token，用户 ID 由后端登录态获取，不接收客户端指定用户。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/app/jobs/{positionId}/favorite` | 返回 `data.favorited` |
| PUT | `/app/jobs/{positionId}/favorite` | 请求 `{"favorited":true}` 或 `false`，返回实际状态 |
| GET | `/app/jobs/favorites?page=1&size=20` | 返回 `data.items/page/size/total/hasNext` |

`positionId` 为正数，page 最小为 1，size 范围 1–100，收藏状态必须是非空布尔值。收藏不存在、未发布或所属企业下架的岗位返回业务码 404；取消收藏允许目标已失效。

复用 `t_usr_interest`，固定 `int_target_type=1`，与企业收藏的类型 2 隔离；按当前登录用户过滤。复用已有唯一索引 `(int_user_id,int_target_type,int_target_id)` 幂等写入，取消使用 `int_status=0`。重复收藏不改变排序时间，重新收藏更新排序时间。无需数据库迁移，不产生企业岗位发布提醒。

列表复用 `AppJob` 与现有岗位、企业、技能、投递关系，增加 `available` 表示当前是否可投递。收藏列表不额外调用 AI，不编造匹配分数。个人中心收藏统计复用现有统计查询，在退出收藏页后刷新。

## 验证与回滚

- Backend：`mvn -B -ntp -pl ruoyi-admin -am test`，覆盖状态确认、当前用户隔离、失效岗位拒绝收藏与允许取消、分页和空列表。
- SQL：`python tools/verify_job_favorites_mysql.py`，使用本机 `DB_PASSWORD`，只在随机独立测试库复制表结构及写入合成记录，退出时清理该库；验证幂等、类型与账号隔离、上下架、分页、取消/恢复和回滚。
- Flutter：修改文件格式检查、`flutter analyze --no-pub`、`flutter test --no-pub`，覆盖真实 HTTP 契约、401、服务端异常脱敏、重复点击、失败保留状态、过期响应隔离、分页重试、详情返回刷新和窄屏大字体布局。
- 设备：更新后端 JAR 和 Android Debug APK 后，检查详情收藏/取消、重新进入保持状态、收藏列表、企业页签及个人中心统计。自动测试不替代尚未执行的设备链路。

回滚对应接口及客户端代码即可；保留原表和已保存收藏数据，无需删表或回滚字段。
