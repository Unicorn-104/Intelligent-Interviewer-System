## 一、背景

项目：`Intelligent-Interviewer-System`

## 二、设计系统（必须严格遵守）

### 2.1 色彩 Token

| Token | 值 | 用途 |
|---|---|---|
| `brand` | `#1A3C6E` | 品牌、页面标题 |
| `brandDeep` | `#102D53` | 深色渐变终点 |
| `interactive` | `#2B7FFF` | 主按钮、链接、选中态 |
| `interactiveSoft` | `#EAF2FF` | 选中背景、信息提示 |
| `ink` | `#080808` | AI Hero 近黑 |
| `background` | `#F5F7FA` | 页面背景 |
| `canvas` | `#FFFFFF` | 卡片、输入框 |
| `hairline` | `#E6EBF2` | 边框、分割线 |
| `textPrimary` | `#172B4D` | 正文 |
| `textSecondary` | `#4D5F78` | 次级正文 |
| `textMuted` | `#6B7A90` | 辅助文字 |
| `success` | `#1B9A72` | 已完成、已通过 |
| `warning` | `#D7811D` | 待处理、即将开始 |
| `error` | `#EE1D36` | 失败、未读、删除 |
| `accentOrange` | `#FF6B00` | 薪资 |
| `accentPurple` | `#7A3DFF` | AI 能力标识 |

**规则**：
- 同一屏只允许一个亮蓝实心主按钮。
- 深蓝用于品牌和标题，不与亮蓝按钮混层级。
- 禁止在页面内散落新的十六进制颜色；新颜色必须先加入 `AppColors`。

### 2.2 字体与间距

- 字体族：`Inter → PingFang SC → Microsoft YaHei`
- 字重最大 `600`，禁止 `800/900`
- 基础间距 `4px`，页面左右边距 `20px`，卡片内边距 `16px`
- 区块间距 `24px`

### 2.3 圆角与组件

- 按钮圆角 `4px`，卡片圆角 `8px`，头像/图标容器圆形
- 按钮最小高度 `46px`，图标点击区 `44×44px`
- 卡片默认白底 + hairline 边框，无阴影
- AI 区域使用 `ink → brandDeep` 渐变，必须带“AI 结果仅供参考”提示

### 2.4 状态要求

所有列表页必须覆盖：**加载中 / 空数据 / 请求失败可重试 / 无权限 / 网络超时**。

## 三、页面结构（4 Tab）

```
底部导航：首页 / 岗位 / 消息 / 我的
```

### 3.1 首页

- **顶部栏**：企业名 + 通知铃铛（未读红点）
- **广告轮播**：PageView，3~4 张，自动 5s，指示器圆点，静态渐变占位图（不用网络图片）
- **即将进行的面试**：
  - 按 `startTime` 升序
  - 默认展示 3 条，右侧“更多”展开
  - 每行：候选人 + 岗位 + 时间 + `[进入面试]` 小按钮
- **新投递简历的岗位**：
  - 按最新投递时间倒序
  - 默认 3 条，“更多”展开
  - 每行：岗位名 + “X 人新投递” + 最新时间
  - 点击进入岗位详情的“求职者”Tab
- **快捷统计**：在招岗位 / 待面试 / 待终审 / 本周完成

### 3.2 岗位（核心 Tab）

- **顶部**：标题“岗位” + 右侧 `[+ 发布岗位]`
- **岗位列表**：
  - 筛选 Chips：全部 / 在招 / 已下线 / 暂停
  - 卡片：岗位名、部门、城市、薪资、状态徽章
  - **右上角投递人数徽标**（红色圆点 + 数字）
  - 点击 → 岗位详情
- **发布岗位页**：
  - 顶部卡片“从文档导入 JD”：支持 PDF / DOCX（≤10MB）
  - 上传后调 `POST /enterprise/jd/parse-document`，返回草稿填充表单
  - 表单字段：title、dept、city、salaryMin/Max、experience、education、jobType、responsibilities、requirements、skills
  - 提交 `POST /system/enterprise/jobs`
- **岗位详情**：
  - 三级 Tab：基础信息 / 求职者 / AI 筛选
  - **基础信息**：JD 画像、招聘流程、右上角“编辑”入口
  - **编辑**：可重新上传文档解析，也可直接编辑字段
  - **求职者**（按投递时间倒序）：
    - 每行：头像 + 姓名 + 投递时间 + 匹配度标签 + `[邀请面试]` `[打招呼]`
    - 点击行 → 候选人详情
  - **AI 筛选**（按匹配度倒序）：
    - 每行：候选人 + 匹配度 + `[邀请面试]`
- **候选人详情页**：
  - 基本信息 + 简历结构化字段
  - 与当前岗位的匹配度分维度展示
  - AI 推荐报告（匹配点 / 风险点 / 待核实点）
  - 底部固定：`[邀请面试]` `[打招呼]`

### 3.3 消息

- **会话列表**：头像 + 姓名 + 最新消息 + 时间 + 未读徽标
- **聊天页**：
  - 顶部：对方姓名 + `[查看信息]`
  - 消息流：左右气泡、时间戳
  - 快捷回复 Chips
  - 输入框 + 发送
- **查看信息**：抽屉或页面，展示候选人信息、投递岗位、简历摘要、匹配度

### 3.4 我的

- 头像 + 昵称 + 企业名
- 账户设置：修改密码、绑定邮箱/手机
- 系统设置：通知、主题、语言
- 退出登录（二次确认）

## 四、接口映射

| 功能 | 接口 |
|---|---|
| 首页面试列表 | `GET /enterprise/interview/list` |
| 首页统计 | `GET /system/dashboard/overview` |
| 岗位列表 | `GET /system/enterprise/jobs/list` |
| 发布岗位 | `POST /system/enterprise/jobs` |
| 文档解析 | `POST /enterprise/jd/parse-document` |
| 岗位详情 | `GET /system/enterprise/jobs/{id}` |
| AI 筛选结果 | `GET /enterprise/screening/tasks/{taskId}/results` |
| 候选人详情 | `GET /enterprise/talent/{id}` + `/resume` |
| 邀请面试 | `POST /enterprise/interview/invite` |
| 打招呼 | `GET /enterprise/screening/results/{id}/greeting` |
| 消息列表 | `GET /system/im/sessions` |
| 消息详情 | `GET /system/im/sessions/{id}/messages` |
| 发送消息 | `POST /system/im/messages` |
| 快捷回复 | `GET /system/im/quick-replies` |
| 用户信息 | `GET /getInfo` |

**禁止修改 `api/` 下现有函数签名、路径、参数。**
