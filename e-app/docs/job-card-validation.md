# 首页岗位卡片样式验证

日期：2026-10-15。分支：`feature/eapp-core-services-zx`。

## 改动与字段来源

- 首页与“更多”独立岗位列表共用 HomeApplicationRow 卡片：白底、8px 圆角、hairline 边框、16px 内边距、卡片间距 12px。
- 岗位名 16px/500/textPrimary，单行省略；右侧薪资 15px/600/accentOrange。
- 企业名从首页 HomeIdentity.company 传入，独立列表沿用同一值；不硬编码企业名。
- 学历枚举 1～5 对应中专/大专/本科/硕士/博士；经验使用 experience 原值。
- 技能只解析原列表响应中的 jdJson.skills：支持 JSON 字符串或已解码对象，清理空值、去重后取前两个字符串；缺失/格式错误不补造技能，也不新增接口请求。
- 标签使用 AppColors.interactiveSoft 背景、AppColors.interactive 文字、4px 圆角、上下 2px/左右 8px 内边距。
- 投递数沿用真实 applicantCount，零值显示“累计投递 0 人”，缺失显示“累计投递 — 人”；仅数字用 interactive 强调。
- 保留 home-job-{id} 标识、onOpen 回调及投递候选人 Tab 跳转。
- 区块标题、说明、“更多”、24px 区块间距与首页数据范围不变。

## 薪资规则

除以 1000、保留一位小数并去掉末尾 .0。

| 原字段（元/月） | 卡片输出 |
| --- | --- |
| 12500 / 20000 | 12.5-20K·月薪 |
| 8500 / 12000 | 8.5-12K·月薪 |
| 仅 min=12000 | 12K起·月薪 |
| 两端均缺失 | 面议 |
| 仅 max=20000 | 20K以内·月薪 |

非数字、非有限值和非正数视为未提供，不伪造缺失端点。

## 包装影响面

HomeSection 只有首页通用 _section 调用，实际承载近期面试、岗位投递概览、快捷统计三个区块。
新增 wrapInCard 默认 true；仅岗位投递概览的成功数据关闭外层包装，避免双层卡片。
其加载/错误/空态保留包装；近期面试与快捷统计始终使用原包装。
独立列表的通用项目包装默认开启，只有岗位列表关闭它并直接渲染同一卡片；面试列表不变。
