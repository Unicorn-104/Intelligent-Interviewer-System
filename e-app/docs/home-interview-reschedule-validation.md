# 首页面试卡片改期入口（2026-10-20）

## 范围

首页“近期面试”日历下的卡片，以及该区块“更多”列表的卡片，在“开始面试”左侧增加“改期”。复用岗位面试安排使用的 `TalentInterviewRescheduleSheet`、原日历/面试官/候选人流程读取和改期API，不修改后端、数据库、底部Tab或页面跳转。

- 仅状态0/1且开始时间晚于当前时间的预约可打开改期。
- 已开始、过期、完成、取消等记录点击后显示中央提示“仅未开始且未取消的面试可以改期”，约2秒自动消失。
- 沿用既有冲突检测、流程阶段时序限制、提交确认、保存中禁止关闭、结果未知不自动重发等行为；不伪报已发送通知。
- 关闭改期面板后重新读取数据：首页刷新当天日历、近期面试和统计；“更多”刷新当前列表，返回首页仍沿用原刷新机制。
- 共享卡片支持宽/窄布局及大字号，保留头像与卡片跳转、状态配色、“开始面试”等行为；岗位页原 `onReschedule` 回调继续优先使用。
