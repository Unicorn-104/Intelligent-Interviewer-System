# 阶段三子功能 4：候选人详情与匹配分析验证

## 实现范围

TalentDetailPage 支持可选 TalentJobContext。岗位详情的求职者入口传入岗位 ID、标题和招聘阶段；人才库入口保持不带岗位上下文的兼容调用。

页面采用蓝白卡片：基本资料卡内展示打招呼（描边）、邀请面试（实心）和独立下拉操作按钮；滚动内容依次为头像及状态、岗位与联系方式、细进度条完整度、教育/工作/项目/技能卡片、AI分析结果卡片和面试记录。AI分析结果在同一张卡内展示通用评分、岗位技能分析与已有推荐报告，使用细分隔线区分内容。去掉“结构化简历”等外层大标题及嵌套卡片，长摘要和报告正文支持展开全文。

状态图标和文字同时展示。初筛通过为绿色勾、面试中为蓝色箭头、已淘汰为红色叉、已录用为绿色勾；其余状态沿用真实 candidate_status 字典。颜色来自 AppColors。

AI分析结果卡片仅在统一标题右侧保留一个信息图标，三个内部区块不重复显示提示图标；简历与招呼语沿用已有信息图标。点击或长按显示完整 Tooltip：“AI 结果仅供参考，评分和报告基于模型分析，不构成录用结论”。

本提交包含岗位上下文入口、候选人详情及其尚未提交的数据源/模型/组件、相关测试和本文档，保证从当前分支检出后依赖完整。未修改后端、既有 API 文件、screens、mock 文件、依赖、公共雷达图或 Android 配置。

## 接口与字段边界

| 用途 | 接口或数据 | 实际字段与处理 |
| --- | --- | --- |
| 基本资料 | getTalentDetail | 状态与 currentRound 不冒充岗位招聘阶段；联系方式不完整时显示未提供 |
| 简历 | getTalentParsedResume | educationList/workList/projectList/skills/integrity/missingFields；独立加载、空态、失败和重试；完整度缺失不补零 |
| 岗位上下文 | getJobDetail / getJdProfile | candidates.talId 对齐候选人；岗位技能仅 required=1 作为必备技能 |
| 通用评分 | getScreeningResults.totalScore / matchedScore | 合并卡内的独立评分分区，始终标注“通用评分，非岗位维度” |
| 岗位技能 | skillMatch | 蓝色进度条与服务返回的实际百分比；无必备技能显示“暂无岗位技能依据” |
| 其他维度 | projectMatch / educationMatch / industryMatch | null 显示“暂无分析”，不补零、不画雷达图分支 |
| 推荐报告 | getRecommendationReport | 只展示 matchPoints/content/status/sentAt；注明“候选人已有报告，未提供岗位归属信息”，不推导风险点 |
| 招呼语 | getGreetingMessage | 只读已有文案，可在面板编辑和预览；本地生成标注“模板草稿，非实时 AI 生成” |
| 面试官 | GET /system/conference/interviewers | 只使用真实企业人员 userId/userName/jobTitle/department；空列表不伪造选项 |
| 忙闲和邀约 | getInterviewerAvailability / sendInterviewInvite | 用户二次确认后才复核忙闲，再调用邀约；取消不增加请求；服务器负责最终冲突校验 |
| 面试记录 | listInterviews | 每页50、最多100、第三页探测超量；按 candidateId 客户端过滤，保留日期筛选、清除筛选和详情入口 |

2026-10-16 对运行中后端的只读核实：当前企业可见7个岗位、共9条候选人评分；只有 skillMatch 有值，另外三个维度均为 null。getJobDetail.candidates 只返回 matchScore 通用评分，不返回上述四个维度。界面因此只实现技能进度条，不修改 radar_chart.dart。

无岗位上下文时显示“选择岗位后查看”，不猜测岗位。AI 区块各自保留加载、空、失败、重试；一个接口失败不清空其他成功区块。

## UTC+8 与提交保护

日期、时间选择器表示 UTC+8 墙上时间。未来时间和时段重叠按 UTC 瞬间比较；提交使用无偏移字符串 yyyy-MM-dd HH:mm:ss。测试覆盖午夜、跨年和跨日占用。忙闲查询不限定 from，避免遗漏开始于前一天的占用。

点击确认邀请先显示“确认发送面试邀约？”对话框，展示已有候选人姓名、岗位、面试官、UTC+8时间及所选时长。点击取消保留选择；点击确认发送后才复核忙闲并提交。重复点击锁定；错误不自动重试；响应缺少预约编号时提示先检查记录。
