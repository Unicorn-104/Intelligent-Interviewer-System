服务器数据库现有115张基础表、1231个字段、8个视图，覆盖企业APP岗位、简历、消息、面试排期、阶段报告和企业设置所需的现有数据库对象。本机111张基础表（含2张本机备份表）、1192个字段；共同业务字段类型、默认值及本机已有索引签名一致。服务器比本机多组织架构、集成配置、面试录制、个人邮件配置、调研发送记录等表，因此没有覆盖或删除服务器额外对象，没有复制本机备份表。

## 唯一未补齐项：数据库管理员触发器门禁

尝试创建六个业务触发器时，服务器返回ERROR 1419：启用二进制日志，当前库级账号缺少所需管理权限。未改全局 `log_bin_trust_function_creators`、未提升应用账号权限、未尝试使用用户未提供的管理凭据。

管理员需审阅并执行 `e-app/new.sql` 2026-10-20追加节A，或单独的 [eapp-required-triggers-20261020.sql](eapp-required-triggers-20261020.sql)：

- trg_app_record_after_insert：投递后的候选人状态。
- trg_tal_status_log_after_update：候选人状态历史。
- trg_process_instance_after_update：招聘流程变更审计。
- trg_exam_record_after_update：笔试记录变更审计。
- trg_exam_schedule_after_update：笔试安排变更审计。
- trg_offer_approval_after_update：Offer审批变更审计。

这些对象当前服务器仍未创建。演示候选人的初始状态历史仅以显式合成快照补入，不能替代后续动态触发器。本机严格审计before-insert触发器会拒绝普通若依日志，未照搬；无操作消息触发器和无关Agent告警触发器也未复制。
