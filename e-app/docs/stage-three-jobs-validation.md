# 阶段三子功能一：岗位列表与累计投递徽标

日期：2026-10-16。分支：`feature/eapp-core-services-zx`。

## 范围

- 岗位页标题、右侧发布按钮、独立搜索行和全部/在招/已下线/暂停筛选。
- 独立 JobListCard：名称、橙色月薪、部门城市、学历经验和最多两个真实 JD 技能。
- 右上角红点+累计投递数，零值显示 0、缺失 —、超过 99 显示 99+，可访问标签保留完整数量。红点不表示新增或未读。
- 徽标进入 JobDetailPage(initialTab: 1)，整卡进入默认 initialTab: 0；删除卡片内“查看详情”文字按钮。
- 状态标签在薪资行右侧；状态按钮为 0→上线、1→下线、2→上线（恢复在招）。未知状态禁用。
- 状态操作先确认，取消不请求；同岗位从弹框到提交完成期间锁定，防重复；错误反馈沿用统一 ApiException。
- 每页 20 条、显式加载更多、按 ID 去重、重复分页保护、后续页失败保留已有记录并可重试。
- 请求序号防止旧搜索/筛选覆盖新数据；新筛选重置第一页。
- 加载、空态、请求失败/重试、401、403、超时分别处理。
- 保留发布成功返回的列表刷新与“查看岗位”入口。
- 原 JobsPage 调用方兼容；可选 loader/updater/builder 注入只供隔离测试使用，默认仍走现有 API 和真实详情页。

2026-10-16 用户在 Pixel_10a 登录后，使用正式 APK 及真实后端补验通过：
